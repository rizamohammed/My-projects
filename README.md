POLLING WEB APPLICATION
A full-stack polling web application developed using Django, Python, HTML, CSS, JavaScript, jQuery, and AJAX. This platform allows users to create interactive polls, cast votes, and view real-time results through visually appealing graphical representations.

🔹 Key Features

Custom Poll Creation
Users can create polls with any number of options based on their requirements.

Voting System
Participants can vote for their preferred option securely and intuitively.

Graphical Result Visualization
Poll results are displayed using attractive and easy-to-understand charts and diagrams.

Centralized Dashboard (Home Page)
The home page provides a complete overview of all poll-related data, including active polls, total votes, and statistics.

Dynamic User Experience
AJAX is used to update content dynamically without page reloads, improving performance and usability.
